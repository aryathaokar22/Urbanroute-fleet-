
# UrbanRoute Fleet — Project Overview

## 1. Project Vision

UrbanRoute Fleet aims to make electric fleet operations more intelligent, energy-aware and resilient.

It focuses on helping fleet operators understand vehicle availability, energy requirements, charging infrastructure and operational disruptions.

## 2. Problem Statement

Electric fleet operators face several operational challenges:

- Limited visibility into vehicle status and battery levels
- Difficulty estimating energy requirements
- Charging coordination challenges
- Delivery commitments affected by vehicle disruptions
- Limited ability to evaluate alternative recovery plans

## 3. Proposed Solution

UrbanRoute Fleet provides a unified platform with:

- Fleet monitoring dashboard
- Vehicle information management
- Charging infrastructure overview
- Assignment tracking
- Energy consumption calculations
- Driving range estimation
- Disruption recovery simulation

## 4. Core Innovation

### UrbanRoute Fleet Resilience OS

The long-term goal is to develop a recovery engine that responds when an original fleet plan becomes infeasible.

Instead of simply assigning another vehicle, the system aims to preserve as many existing commitments as possible while respecting operational constraints.

## 5. Target Users

- Electric fleet operators
- Delivery companies
- Logistics businesses
- Fleet managers
- Electric mobility service providers

## 6. Development Roadmap

### Phase 1 — MVP
- Flask application
- SQLite database
- Fleet dashboard
- Vehicle, charger and assignment pages
- Energy and range calculators
- Basic disruption simulation

### Phase 2 — Intelligence
- Fleet dependency modelling
- Vehicle eligibility engine
- Charging coordination
- Constraint-based recovery planning

### Phase 3 — Advanced Platform
- Live telemetry integrations
- Traffic-aware planning
- Predictive energy intelligence
- Recovery plan evaluation
- Learning from operational outcomes

## 7. Current Project Status

The project is being developed as a functional MVP using demonstration data.

Live integrations and advanced recovery intelligence are future development goals.
