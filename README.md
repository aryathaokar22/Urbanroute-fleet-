
# UrbanRoute Fleet

### Intelligent Electric Mobility Operations Platform

UrbanRoute Fleet is an electric vehicle fleet operations platform designed to improve fleet visibility, energy awareness, charging coordination and operational resilience.

## Core Modules

1. Vehicle Intelligence
2. Charging Infrastructure Management
3. Fleet Assignment Management
4. Energy Consumption Calculator
5. Driving Range Estimator
6. UrbanRoute Fleet Resilience OS
7. Disruption Recovery Simulation

## Technology Stack

- Python
- Flask
- Flask-CORS
- SQLite
- HTML
- CSS
- JavaScript

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd "URBANROUTE FLEET"
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python3 app.py
```

Open in your browser:

http://127.0.0.1:5000
