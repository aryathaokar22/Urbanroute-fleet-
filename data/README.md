
# UrbanRoute Fleet — Data

This folder contains datasets used by UrbanRoute Fleet.

## Current Data Status

The initial MVP uses demonstration data stored in:

`instance/data/seed_data.py`

The application initializes its SQLite database using this data.

## Future Dataset Requirements

Future versions may include:

- Vehicle telemetry data
- Battery and energy consumption records
- Charging station availability
- Fleet assignments and delivery commitments
- Traffic and route information
- Disruption and recovery history

## Important

The current demonstration dataset is not live vehicle or charging station data.
